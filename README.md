# Dotfiles

Dotfiles for macOS and Linux (Ubuntu), managed with a bare git repo.

## How it works

A bare git repo lives at `~/.dotfiles` with `$HOME` as the work tree. The `dot` alias wraps git to target this repo:

```bash
alias dot='/usr/bin/git --git-dir=$HOME/.dotfiles --work-tree=$HOME'
```

This avoids putting a `.git` directory in `$HOME`, so editors, prompts, and scripts in `$HOME` or non-repo subdirectories don't pick up the dotfiles repo. `status.showUntrackedFiles = no` is set in the repo config, so `dot status` only shows changes to tracked files.

`~/CLAUDE.md` is deliberately not tracked: each machine keeps its own notes there.

## Tracked files

- `.zshrc` - zsh config, sources oh-my-zsh, defines `dot` alias
- `.zprofile` - zsh profile
- `.p10k.zsh` - powerlevel10k prompt configuration (generated by `p10k configure`)
- `.gitconfig` - git aliases and settings
- `.gitmodules` - submodule definitions
- `.tmux.conf` - tmux configuration
- `.config/ghostty/config` - Ghostty terminal config
- `.config/nvim/` - neovim config ([LazyVim](https://www.lazyvim.org) based)
- `.config/zellij/config.kdl` - zellij terminal multiplexer config
- `.claude/settings.json` - Claude Code settings
- `.claude/scripts/context-bar.sh` - Claude Code status line script

## Submodules

- `.tmux/plugins/tpm` - tmux plugin manager
- `.tmux/plugins/tmux-resurrect` - tmux session save/restore
- `.tmux/plugins/tmux-continuum` - automatic tmux session saving
- `.oh-my-zsh/custom/themes/powerlevel10k` - zsh prompt theme

## Setup on a new machine

### 1. Install tools

**macOS** (with [Homebrew](https://brew.sh)):

```bash
brew install neovim git ripgrep fd fzf lazygit tree-sitter-cli node tmux gh
brew install --cask ghostty tailscale-app
curl -fsSL https://herdr.dev/install.sh | sh
```

**Ubuntu**:

```bash
sudo apt-get install -y zsh neovim git ripgrep fd-find fzf lazygit tree-sitter-cli \
  nodejs npm build-essential unzip tmux ncurses-term
mkdir -p ~/.local/bin && ln -sf /usr/bin/fdfind ~/.local/bin/fd

# Tailscale (official apt repo)
curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up

# GitHub CLI (official apt repo)
sudo mkdir -p -m 755 /etc/apt/keyrings
curl -fsSL https://cli.github.com/packages/githubcli-archive-keyring.gpg \
  | sudo tee /etc/apt/keyrings/githubcli-archive-keyring.gpg >/dev/null
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/githubcli-archive-keyring.gpg] https://cli.github.com/packages stable main" \
  | sudo tee /etc/apt/sources.list.d/github-cli.list >/dev/null
sudo apt-get update && sudo apt-get install -y gh

# herdr (installs to ~/.local/bin; update with `herdr update`)
curl -fsSL https://herdr.dev/install.sh | sh

# Ghostty terminfo: Ubuntu ships it as `ghostty`, but Ghostty sets TERM=xterm-ghostty
infocmp -x ghostty | sed 's/^ghostty|/xterm-ghostty|ghostty|/' | sudo tic -x -

sudo chsh -s /usr/bin/zsh "$USER"
```

Neovim must be 0.11.2 or newer for LazyVim. Check with `nvim --version`.

### 2. Install oh-my-zsh

Do this before checking out the dotfiles: the installer refuses to run if `~/.oh-my-zsh` already exists, and the powerlevel10k submodule lives inside it.

```bash
RUNZSH=no CHSH=no KEEP_ZSHRC=yes sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
```

### 3. Check out the dotfiles

```bash
gh auth login   # or add an SSH key to GitHub
git clone --bare git@github.com:mikekelly/dotfiles.git ~/.dotfiles
alias dot='/usr/bin/git --git-dir=$HOME/.dotfiles --work-tree=$HOME'
dot config status.showUntrackedFiles no
dot checkout
dot submodule update --init --depth=1
```

If `dot checkout` complains about existing files (e.g. the `.zshrc` oh-my-zsh created), back them up first:

```bash
dot checkout 2>&1 | grep -E "^\s+" | awk '{print $1}' | xargs -I{} mv {} {}.bak
dot checkout
```

### 4. Neovim

Start `nvim` once; lazy.nvim installs LazyVim and the plugins pinned in `lazy-lock.json`. Language servers install via Mason; to install them up front:

```bash
nvim --headless -c "Lazy! load mason.nvim" -c "MasonInstall pyright vtsls elixir-ls" -c qa
```

## Neovim keymaps

The config is LazyVim plus everything from the pre-LazyVim setup. Where LazyVim's defaults clashed with old bindings, the old binding wins:

- `\n` Neo-tree, `\o` Overwatch, `\/` comment, `\t` open in Typora (macOS)
- `<C-p>` find files, `<Space>fg` live grep, `<Space>fb` buffers (Telescope)
- `<C-]>` definition, `gr` references, `K` hover, `<Space>rn` rename
- `]h`/`[h` Overwatch hunks, `<C-S-^>` alternate buffer
- easymotion on `<Space><Space>` (LazyVim's `<Space><Space>` find-files is removed)
- vim-surround (`ys`/`cs`/`ds`, visual `S`), so flash.nvim is disabled and `s`/`S` are vim's own
- vim-unimpaired keeps all its `[x`/`]x` pairs (LazyVim's `[e`/`]e`, `[q`/`]q`, `[b`/`]b`, `[t`/`]t` and treesitter's `[f`/`[a`/`[c` moves are removed)
- `H`, `L`, `n`, `N` are plain vim again
- relative numbers and system clipboard are off, as before

## Usage

```bash
dot status
dot add .zshrc
dot commit -m "Update zshrc"
dot push
```

- **Adding submodules**: `dot submodule add <url> <path>`
- **Branches**: `master` is the active branch
